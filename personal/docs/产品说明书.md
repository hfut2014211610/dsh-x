# DSH-X 产品说明书

> 版本：v0.2.0+（跟随上游 `master` 持续更新）

---

## 1. 产品概述

DSH-X 是基于 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（简称 `dsh`）的个人分支产品。dsh 是一个基于 Cordis 构建的插件化智能体框架，其核心理念是"一切皆插件"。

DSH-X 在完整跟踪上游 `master` 分支的基础上，额外携带了自身的产品化能力层，主要包括：

- 桌面端外壳（Desktop Shell）
- 锚定标准预设（Anchored Standard preset）
- 用量统计界面（Usage surface）
- 个人化配置层（Personal layer）

DSH-X 适用于需要在桌面环境中便捷运行智能体服务、并希望获得开箱即用插件预设与用量统计能力的开发者与个人用户。

---

## 2. 产品功能

### 2.1 桌面端外壳（Desktop Shell）

- 基于 Electron，在 `dsh --profile web` 运行时的外层提供原生桌面窗口；
- 支持运行时自动发现（runtime discovery）；
- 支持托盘常驻（tray persistence），关闭窗口后程序继续在后台运行；
- 首次运行时自动解压内置运行时（first-run bundled-runtime extraction），无需手动配置；
- 提供 Windows 与 macOS 安装包：
  - Windows：NSIS 安装包 + 便携版（portable）；
  - macOS：dmg 安装包（arm64 + x64）；
- 每个发布版本的安装包内置**由该发布标签（tag）本身构建**的运行时，而非来自 npm 仓库的运行时，保证版本一致性与可复现性。

### 2.2 锚定标准预设（Anchored Standard）

- 由社区项目 [`dsh-anchored-standard`](https://github.com/xiaobright/dsh-anchored-standard) 移植而来，作为名为 `anchored-standard` 的智能体预设提供；
- 请求 #1 锚定在 Minimal 双工具、零注入条件下运行；
- 在第一次持久回复或工具调用之后，目录（catalog）将提升为按需解锁的常驻工具集（resident set），包含：
  - `dev_tool_search`
  - `skill_search`
  - `skill_load`
- 阶段状态由持久会话事件推导；
- 压缩（compaction）边界会重新进入受控阶段。

### 2.3 用量统计界面（Usage Surface）

- 按请求提供模型 token 用量统计，并以会话投影（session projection）形式呈现；
- 提供 `/usage` 报告命令，可随时查询用量；
- Web 界面提供"模型用量"（Model-usage）设置面板。

### 2.4 个人化配置层（Personal Layer）

- 位于 `personal/` 目录，包含本地模型中心（model-hub）预设与插件；
- 本部署环境的默认 Web 端口为 **13080**。

## 3. 安装说明

### 3.1 系统要求

| 平台 | 要求 |
| ---- | ---- |
| Windows | 支持 NSIS 安装版与便携版（无安装需求） |
| macOS | arm64 或 x64 架构，dmg 安装包 |

### 3.2 安装步骤

1. 前往 [Releases 页面](https://github.com/hfut2014211610/dsh-x/releases) 下载对应平台的安装包；
   - `dsh-v0.2.0` 是首个携带桌面安装包的发布版本。
2. 运行安装包完成安装：
   - Windows：运行 NSIS 安装程序，或直接解压便携版；
   - macOS：打开 dmg 文件并将应用拖入"应用程序"文件夹。
3. 首次启动时，程序会自动解压内置运行时，完成后即可正常使用。

### 3.3 代码签名说明

- 仅在配置了发布密钥（release secrets）时安装包才会进行代码签名；
- 未签名时，安装包仍然有效可用，仅缺少数字签名（系统可能提示未知发布者）。

## 4. 从源码运行

### 4.1 环境要求

- Node.js 与 `pnpm` 包管理器；
- Git。

### 4.2 运行步骤

```sh
git clone https://github.com/hfut2014211610/dsh-x.git
cd dsh-x
pnpm install
pnpm run build
pnpm dsh web
```

- Web 界面默认地址：`http://127.0.0.1:13080`（本部署环境）。
- 如需开发桌面外壳：`pnpm run dev:desktop`。
