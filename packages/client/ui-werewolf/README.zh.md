# dsh-client-ui-werewolf

[English](README.md) | 中文

独立狼人杀应用窗口：带准确 `{ id, revision }` 规则集卡片且可恢复已有对局的大厅、刻意的遮盖式身份揭示、含公开时间线与真人私有栏的昼/夜游戏桌、封闭规格词汇之上的通用动作表单、观战状态、带确认保护的暂停/恢复、全身份揭示的结算，以及授权复盘。游戏窗口不包含会话界面，并提供唯一的专用关闭入口；本插件不注册任何命令，也没有 Chat 变更路径。

## 它做什么

- **独立窗口** —— 注册全局 `sidebar.footer.action` 入口，打开具名 `dsh-werewolf` 窗口。带 `dshMode=werewolf` 的 URL 会选择 `shell.surface` 条目，与主窗口当前 Session 无关；游戏 URL 保留 `gameId`，专用退出只关闭该窗口。标准 preset 切换器、Session 侧边栏、会话区、详情区、覆盖层与拖动手柄不会在其中挂载。
- **持久返回路径** —— `getLobby` 按新到旧列出本地主体可访问的运行中与已暂停 Host 投影。关闭窗口或切换主会话不会丢失对局；再次打开入口会显示由 `ctx.games.listViews()` 支持的“继续游戏”，不依赖浏览器局部存储。普通 Session 导航排除游戏 Host Session，preset 列表也不包含狼人杀条目。
- **类型化 Remote 动词** —— 注入面包装 `ctx.remote.werewolfGame`（`getLobby`、`start`、`getView`、`submitAction`、`resume`、`abortGame`、`getReplay`），把 `RemoteResult` 解包为视图值或抛出诊断，前端以内联可重试错误呈现。
- **失效刷新** —— 首次读取前订阅转发的 `game/projection-invalidated` 宿主事件，忽略其他游戏的事件并通过 `getView` 重读；旧修订不能覆盖当前投影，同一阶段刷新会保留仍适用的草稿与选择。
- **交互状态** —— 可恢复大厅、遮盖揭示（两步交互，不依赖翻牌动画）、每个座位使用一个中性徽记并带粘性阶段标题的 Signal Circle 游戏桌、授权可见的队友标识、带隐私提示的夜间聚焦、显示当前发言人/进度与按序发言或明确过麦记录的白天轮流发言、带单选组选择与粘性确认的投票、观战标注，以及带复盘检查点的结算。全部计划中的存活座位完成发言或过麦后才会出现投票。独占外壳只包含游戏自有动作，因此普通 Chat 输入与无关系统交互不会进入当前模式。
- **私密发现** —— 只有 `view.self.notices` 能把座位标记为已知。已知座位控件和私有栏打开同一份发现详情；内置查验展示目标、本地化阵营与来源天数，配置化通知类型则保留可读的键值兜底。
- **通用动作表单** —— 只渲染封闭规格词汇：`player-target`、`choice`、`text`、`compound`；字段 id 稳定，复合文本字段各自保留草稿，必填字段控制提交可用性，可见的“过/弃票”会提交显式 null 动作。配置无法携带 HTML、CSS、回调或组件名。
- **无障碍** —— 座位以文字公告状态，键盘按 DOM 顺序可达所有控件，单选组支持方向键选择与 Escape 清除并使用 `role="radio"`/`aria-checked`，忙碌、阶段与错误区域使用实时语义，已提交的阶段切换后焦点返回阶段标题。
- **失败恢复** —— 内联重试使用原幂等键重发同一逻辑变更。客户端在提供变更重试前会先刷新授权投影；若阶段已经推进，则不再保留过期动作。

## 模型体验

None, as the game view renders host-authorized projections in the browser; view actions create no parent model request.

#### KV Cache effect

None；本包既不组装也不发送 provider 请求，整局固定的逐座位游戏 Bot Session 由 Host 持有，并刻意不进入通用子代理目录和原生弹窗。

## 已知限制与遗留工作

- **尚无展示 store** —— 草稿、侧栏状态与动画开关仍是组件局部的；跨刷新的注册客户端展示 store 随打磨阶段交付。
- **复盘按检查点索引** —— 复盘列出授权修订，尚无按天/阶段 scrub；scrub 式复盘随阶段5文档批次到来。
- **尚无图像回归框架** —— 具名视口快照覆盖 DOM 结构，不覆盖计算后的 CSS 几何或对比度；这些属性仍需在真实浏览器中评审。
- **无角色肖像或装饰性卡图** —— 遮盖身份牌仍使用中性背纹，座位徽记不表达角色或阵营；图片加载失败时，文字仍保留全部座位与发现状态。
