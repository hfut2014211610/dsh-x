# Agent Note: 从 DSH 移除狼人杀实验

Status: implemented

[English](2026-08-29-remove-werewolf-experiment.md) | 中文

## 问题

狼人杀实验在 DSH 主仓库中加入了通用游戏运行时、确定性狼人杀引擎与规则集、持久角色 Bot、Remote API、独立浏览器应用、预设、生成目录、文档以及桌面发布接线。它用于验证持久 Agent Session 与投影能否支持多角色游戏，但形成的产品方向没有为通用 Agent Harness 带来足够价值，无法抵偿其包、发布和维护成本。

即使不再挂载实现，保留代码仍会保留依赖图、事件术语、公开类型、文档义务、构建时间和发布载荷。通用游戏运行时没有狼人杀之外的当前消费者，这些抽象也违反了仓库对每个已发布抽象必须有当前所有者和需求的要求。

## 决策

DSH 不发布游戏运行时或狼人杀应用。活跃源码树与发布输入中不存在 `packages/game` 包组、`client/ui-werewolf`、狼人杀预设、游戏事件与 Remote API、Web 和桌面入口、生成目录条目、子系统文档，以及功能专属测试和 Agent Note。

实验的最后源码仅保留在远程废弃快照 `codex/archive/werewolf-deprecated-20260829` 的提交 `8c42340a8d67dee9136546c1a2554d828417e538`。该分支只用于历史恢复，不是受支持的产品线或文档权威。

本 Note 合并吸收被删除的确定性核心、Session Host、Bot Runner、会话视图、隔离应用与可配置模式决策。它们最初用于验证确定性隐藏信息规则、每座位持久 Agent 连续性、可重放 Session Event 以及聚焦的单人界面。完整删除源于产品范围决策，不表示这些机制在技术上无效。

## 备选方案

- **保留包但不挂载。** 否决：未使用的包仍会扩大依赖解析、类型聚合、生成参考、验证义务以及发布载荷风险。
- **把实现移到 `experimental/`。** 否决：仓库内实验目录仍需持续跟进 Session、Remote API、Client、打包和文档变化。
- **只保留通用游戏运行时。** 否决：狼人杀是它唯一的生产消费者；保留没有当前用户的推测性能力，会留下没有所有者和验收路径的抽象。
- **在独立产品仓库继续狼人杀。** 如果以后出现明确的产品所有者与验收计划，这是推荐的重新引入路径。它把游戏专属发布和 UX 决策留在通用 DSH 发行版之外，同时可通过已发布接口使用选定的 Harness 能力。

## 结果

- DSH 放弃内置确定性狼人杀引擎、经典七人快速规则、持久座位 Bot、重放投影、专属 UI 和一条命令启动的狼人杀 Profile。
- 主干包发现、TypeScript 聚合、Web 组合、Remote API、生成目录、文档以及桌面发布输入不包含游戏或狼人杀入口。
- 现有预发布狼人杀 Session 和事件日志没有兼容性承诺，不再作为受支持主干应用读取。
- 重新引入需要当前产品所有者、隔离的发行边界、明确的 Session 与隐藏信息安全评审、面向产品的快照覆盖，以及独立于废弃分支的验收计划。
