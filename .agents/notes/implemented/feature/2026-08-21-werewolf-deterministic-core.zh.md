# Agent Note: 狼人杀阶段1——确定性核心

Status: implemented

[English](2026-08-21-werewolf-deterministic-core.md) | 中文

## 问题

[可配置狼人杀模式提案](../../rejected/feature/2026-08-20-configurable-werewolf-mode.zh.md)按阶段交付，要求在任何可玩界面上线之前，确定性基础就能在无模型参与的情况下被证明。阶段1必须在代码中回答三个问题：规则集配置如何选择已注册机制而不引入可执行代码；一份会话日志如何成为整局游戏的唯一权威记录（回放、恢复、fork）；Bot 的主观状态放在哪里才永远不会冒充游戏事实。完整的交互设计（Bot 运行器、投影、专用视图）刻意不在本阶段。

## 决策

落地 `packages/game/` 两个包：`@deepseek-ai/dsh-werewolf` 持有核心；`@deepseek-ai/dsh-werewolf-classic` 持有经典定义与 `quick-7` 规则集。阶段1决策：

1. **引擎与回放共用一个 reducer。** 每个引擎步骤先计算下一批事件，再经 `applyWerewolfEvent` 折叠——与回放同一条路径。实况对局无法偏离回放，因为从事件到 `WerewolfGameStateV1` 只有一条路。
2. **游标由事件派生。** `phase-opened` 事件携带 `segment`/`cursorIndex`/`occurrence`/`day`；reducer 只记录它们，`positionConsumed`（由结算与跳过置位）是唯一额外状态。`openNextWerewolfPhase` 仅凭状态推导下一位置，因此重启恢复不需要引擎私有记忆。重投在结算步骤自己的事件批次内以 `occurrence + 1` 重开同一位置。
3. **封闭动作规格词汇**（`player-target`、`choice`、`text`、`compound`）是全部合法性语言。动作计划用它描述每个行动者；引擎通用校验动作；配置永远无法夹带逻辑。真人表单字段（阶段4）从同一词汇派生。
4. **平票策略按行动能力分治。** `voteTie` 需要重新进入调度，由引擎拥有（含重投重开）；`wolfTie` 是夜间击杀的内部事务，由阶段在 `resolve` 内用种子抽取器应用。双方都不窥探对方语义。
5. **随机性是单条被记录的流。** 座位洗牌、角色分配、档案分配与种子平票裁决推进同一个种子计数器，记录在 `game-started`、`phase-opened`、`phase-resolved` 上。回放只应用已记录结算、绝不重跑定义，但恢复的游戏精确延续该流。
6. **Bot 连续性上下文是可重算检查点的受限主观数据。** 每个被接受的决策记录前一个修订、动作、经校验增量与完整 `contextAfter`；包不变量从前一检查点加增量重算每个 `contextAfter`，不一致即拒绝。档案来自固定目录，由种子确定性分配。
7. **死亡属于黎明。** 夜间击杀只在 outcome 与私密通知中记录受害者；`day.announce` 从 `sameDayHistory` 读取夜间结果并发出淘汰。这保持每次结算都是声明式的，让女巫的救人与击杀交互而无需复活逻辑。

## 后果

- 大厅“两套规则集”验收标准（不改引擎即可切换牌组、选项、阶段顺序、平票策略、胜利条件）今天即可测试：注册定义并编译规则输入覆盖了该标准点名的全部内容。
- 不变量伴随插件校验追加与加载语义：连续修订、同一时刻至多一局有效游戏、合法转换、唯一动作 id、行动者资格与顺序、上下文修订连续性与重算快照、结算玩家引用、资源下溢、胜利证据形状。候选事件先在暂存 fold 上校验，只有事件成功提交后才发布该 fold。
- 阶段2的 Bot 运行器不需要事件或 reducer 改动：决策条目已携带子代理 prompt 可重建的一切，`bot-attempt-failed` 已为重试就位。
- 受信任阶段事实已携带阵营，classic 预言家会把查验阵营记录到角色状态和私密通知。后续阶段仍需补齐的内容是：公告文案只有键没有本地化，尚无真人投影和专用视图。

## 备选方案

**引擎内折叠、回放另写折叠。** 状态派生逻辑重复会让实况与回放可能不一致；单一 reducer 以“引擎通过自己追加的同一批事件载荷构造输入”为代价消除了整类缺陷。

**由运行时控制器持有游标。** 控制器拥有的游标随进程消失；`phase-opened` 事件上的位置字段让重启恢复成为普通回放的一种形式。

**现在就用 JSON-Schema 描述 Bot 动作。** 计划中的对象根 schema 属于阶段2子代理运行器，那是它唯一的消费者；封闭规格词汇已为 Bot 与未来的真人提供了完整的合法性校验。

**把资源状态藏进不透明的角色状态。** 独立的命名资源让不变量能通用检查下溢，让未来真人视图无需理解每个角色的 JSON 即可渲染数量。
