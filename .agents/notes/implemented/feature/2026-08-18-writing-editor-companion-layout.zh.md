# Agent Note: 带伴随对话栏的写作编辑器

Status: implemented

[English](2026-08-18-writing-editor-companion-layout.md) | 中文

## 问题

写作会话需要同时进行文档编辑与模型协作。通过视图 tab 切换会让用户为了阅读或发送消息而离开文档；在写作插件内实现第二套聊天则会重复消息流状态、composer 行为、审批、队列处理以及后续会话变更。只有路径输入框的打开方式还要求用户记住工作区结构，文档发现效率较低。

手工修改与模型修改还会写入同一文件。`documents/changed` 事件通知出现更新版本时，浏览器编辑器不得覆盖尚未保存的本地草稿。

## 决策

`ui-conversation` 暴露 `ctx.conversation.declareCompanionView(resolver)`。resolver 针对一个会话和活跃视图返回已注册的 `conversation.view` id 与本地化面板标题。会话主体通过既有子视图 render share 渲染活跃视图与伴随视图，同时保留唯一的 chat store 与常驻 composer。缺失、指向自身或尚未注册的伴随视图 id 会被忽略。

`ui-writing` 仅在 `agentPreset` 为 `writing` 的会话中、`writing` 视图活跃时，把 Chat 声明为伴随视图。该状态隐藏会话 tab 栏。编辑器占据主栏并带有窄文档工具轨；现有 Chat 视图在伴随栏获得独立滚动区，现有 composer 位于该栏底部。没有伴随视图的会话继续使用普通单视图布局。

优先视图声明是可逆覆盖，而不是仅在用户未选择 tab 时使用的默认值。`agentPreset` 为 `writing` 期间，已注册的 Writing 视图优先生效，但不会修改持久化 tab。根组件、页头与会话主体都会订阅解析后的偏好，因此空白会话会在 preset 切换后立即离开 Hero，返回其他 preset 时则恢复 Hero 或之前活跃的 tab。由于 Hero 消失时其 preset chip 也会随之消失，会话页头的 preset 表层会在会话仍为空白时复用同一选择器，并在第一个轮次开始后变回原有只读标签。

写作视图围绕专注的源码编辑区提供文件、大纲和工作区搜索面板。文档服务每次列出一个有界的工作区相对目录层级。文件面板自动加载根目录，仅在目录行展开时读取子级；从目录树打开文件后，面板保持可用，便于继续切换。成功打开或重新载入文档，以及读取或保存失败时，会刷新文档的父目录结果，但不改变已展开目录集合。Markdown 文档默认显示共享草稿的渲染预览，可切换回源码编辑而不触发读写。大纲 locator 会在不离开预览模式的情况下选中匹配的渲染标题；源码模式把 locator 解析为精确文本范围，聚焦该范围并滚动 textarea 使其可见。行 locator 能区分标题相同的条目。保存显式触发，并携带最近一次读取返回的版本。匹配当前文档的 `documents/changed` 事件会在编辑器未修改时重新载入文档；草稿与最近保存内容不同时，编辑器保留草稿并显示冲突提示，由用户显式选择重新载入。

## 考虑过的替代方案

**继续让 Writing 与 Chat 使用互斥 tab。** 该方案无需扩展现有视图环，但每次模型交流都会打断文档上下文，也不满足同时协作。

**从 ui-writing 导入并渲染 ChatView。** 该方案违反客户端插件隔离，让写作插件了解会话内部实现。重新实现聊天也会产生分叉的状态与行为。

**为写作会话替换 conversation 壳层。** 该方案能直接实现布局，但会从 `ui-conversation` 手中接管 composer 与所有会话子 slot，破坏可选审批、dock、输入控件及后续贡献项。

**使用 `host.listDirectory` 构建文件树。** 该 API 为工作区选择列出目录并返回宿主绝对路径，而写作面板需要文件与工作区相对文档路径。让文档发现继续由 `ctx.documents` 负责，可保留包含检查，也不会把工作区选择器扩展成文件浏览器。

## 后果

伴随视图声明是可复用的呈现扩展，但刻意只支持一个次要视图，而不是任意窗格树。写作工作区以桌面为主，并限定伴随栏宽度；较窄的桌面窗口仍保留 320 px 助手栏，由编辑器栏承担收缩。目录浏览不会预先递归扫描；每个层级都有可配置的结果上限，并在目录树中报告截断。

系统仍只有一个会话消息流、输入状态机与 composer。进入 Writing 不会清除用户之前的 tab 选择，离开时也无需重建布局状态。在引入格式专用浏览器编辑器前，Markdown 源码编辑仍为纯文本，显式保存仍是可见限制。

聚焦 GUI 用例约束空白会话立即进入、Hero 与之前 tab 恢复、空白会话页头选择器、伴随视图渲染、普通会话回退、目录按需展开、目录树切换文档、打开／重新载入／失败后的定向父目录刷新、预览与源码模式下含重复标题的大纲导航、新窗口 URL、读取失败及未保存草稿冲突保护。组装 Web 回放覆盖大纲导航及完整的进入／退出布局；视觉对比覆盖组合工作区。
